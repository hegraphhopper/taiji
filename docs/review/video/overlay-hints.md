# 屏幕提示文案（录制时叠加）

## 0 使用方式

- 在录屏画面上方叠加一条半透明提示条，高 36–44 px，圆角 6 px，背景 `#1F2D3D`，透明度 85%，文字白色。
- 字号 20–24 px；每条只放一行，不超过 24 个汉字。
- 提示条在切换步骤时出现，停留 3–5 秒后淡出；与口播不重复念出。
- 可选：在目标元素外加 2 px 高亮边框（`#409EFF`），持续 2 秒。

## 2 字幕样式建议

- 位置：画面底部居中，距底边 40–60 px。
- 字体：思源黑体 / 微软雅黑，字号 28–32 px，白色，黑色描边 3 px 或半透明底条。
- 每行不超过 18 个汉字；`demo.srt` 已按短句切分，导入后一般无需再断行。
- 不要遮挡页面关键按钮与表格首行。

## 3 高亮与箭头

- 只在高亮目标时使用，避免全程闪烁。
- 箭头用于“点击趋势点”“导出报告”两处，其余用边框高亮即可。
- 高亮与提示条不同时出现超过 2 个，避免画面拥挤。
