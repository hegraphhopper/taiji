# 五分钟演示视频 口播稿

## 0 录制说明

- 语速：每分钟约 200 字，句间停顿 0.3–0.5 秒，段落之间停顿 1 秒。
- 语气：陈述为主，重点句稍加重音（加粗部分）。
- 与字幕关系：以下每行对应 `demo.srt` 的一条字幕，时间码一致；如临场语速变化，以画面节奏为准，回剪时对齐字幕。
- 不需要念出时间码与括号内容。

## S1 开场（0:00–0:30）

- 00:00 自投研发项目逐年增多。
- 00:04 同一方向重复立项、跨组近似投入。
- 00:08 同期并行申报，靠人工很难发现。
- 00:13 本平台把申报书结构化，量化重复度。
- 00:18 并解释重复出现在哪里、为什么发生。
- 00:23 下面用五分钟演示完整流程。

## S2 申报（0:30–1:20）

- 00:30 项目组登录后进入项目管理。
- 00:35 列表可按状态、项目组、技术方向筛选。
- 00:40 打开项目详情，申报内容已经结构化。
- 00:45 目标、研制内容、关键技术、节点和成员。
- 00:50 上传申报书后，系统自动解析正文。
- 00:55 识别章节并回填，减少重复录入。
- 01:00 右上角显示状态和可执行动作。
- 01:04 提交前还可以先做一次重复度预检。
- 01:09 内容完整后提交，进入形式审查。
- 01:15 申报内容就是后续查重的输入。

## S3 分析（1:20–2:20）

- 01:20 基金办在分析运行页触发分析。
- 01:25 支持全量运行和单项目运行。
- 01:30 系统对全部非草稿项目两两比对。
- 01:35 五个维度分别打分。
- 01:40 目标、研制内容、关键技术。
- 01:45 节点计划和技术标签。
- 01:50 再按权重合成为零到一百分。
- 01:55 每个项目只保留最相似的前 K 个对手。
- 02:00 项目详情能看到最高分、等级和相似项目。
- 02:05 以及重复片段和差异片段。
- 02:10 大模型是可选增强，失败自动降级。
- 02:15 不影响本地分与趋势口径。

## S4 趋势（2:20–3:20）

- 02:20 更重要的是趋势。
- 02:25 趋势页按月聚合平均最高重复度。
- 02:30 高风险项目数和对数。
- 02:35 并把重复来源拆成四类。
- 02:40 本组内部、他组在先、我方在先、同期并行。
- 02:45 切换项目组或技术方向，图表联动。
- 02:50 热力图显示重复集中在哪些组和方向。
- 02:55 点击趋势点可以下钻到当月项目。
- 03:00 再进入项目对，查看具体重复技术点。
- 03:05 治理动作就能落到具体的组和项目。
- 03:10 结论摘要中的数字与图表同源。
- 03:15 也可以导出 CSV 留档。

## S5 投入与决策（3:20–4:05）

- 03:20 投入态势把重复度换算成预算风险。
- 03:25 显示总投入、项目数和平均重复度。
- 03:30 风险敞口等于预算乘以最高重复度。
- 03:35 辅助决策页对新项目做预检。
- 03:40 输出风险等级和最相似的五个项目。
- 03:45 以及重复点、差异点和建议动作。
- 03:50 并估算可能重复投入的金额。
- 03:55 规则可按阈值、归因和同组条件配置。

## S6 治理与报告（4:05–4:45）

- 04:05 最后是治理闭环。
- 04:10 专家在评审任务中打分并给出结论。
- 04:15 基金办在 PASS 数达标后立项。
- 04:20 状态流转进入审批轨迹。
- 04:25 写操作全部进入审计日志。
- 04:30 决策记录可以导出 Word 和 Excel。
- 04:35 报告包含相似项目、重复点和口径说明。
- 04:40 便于离线评审和归档。

## S7 收尾（4:45–5:00）

- 04:45 平台采用 Spring Boot 与 Vue 3。
- 04:49 本地 H2 一键启动，生产可切 MySQL。
- 04:53 全量测试与前端构建均通过。
- 04:57 演示结束，谢谢观看。
