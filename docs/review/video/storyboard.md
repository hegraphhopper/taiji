# 五分钟演示视频 分镜脚本

## 0 使用说明

- 总时长 5:00，7 个段落，口播与字幕见 `narration.md`、`demo.srt`。
- 屏幕提示条文案见 `overlay-hints.md`，录制参数见 `recording-guide.md`。
- 录制前确认：演示数据为 60 项目基线，趋势有 14 个月数据点，模型默认关闭（不依赖外部接口）。
- 画面统一 1440×900，浏览器缩放 100%，隐藏书签栏与无关通知。

## 2 分段操作细则

### S1 开场（0:00–0:30）

1. 打开 `http://127.0.0.1:5173`，停在登录页 2 秒。
2. 输入 `admin / Admin@123`，点击登录。
3. 工作台加载完成后停留，鼠标缓慢移动到左侧菜单。
4. 预期：工作台显示角色化入口与概览卡片。
5. 注意：不要出现浏览器密码保存弹窗。

### S2 申报（0:30–1:20）

1. 点击“项目管理”，在项目组筛选器选择“智能计算项目组”。
2. 打开第一个非草稿项目，展示“概览”页签 3 秒。
3. 切到“申报内容”，滚动展示目标、研制内容、关键技术。
4. 切到“节点与成员”，展示节点计划与成员人月。
5. 切到“附件”，点击“预览回填”，展示章节预览弹窗 3 秒后关闭（不上传新文件，避免录制中断）。
6. 停留右上角状态与动作按钮 2 秒。
7. 预期：字段完整、页签切换流畅、弹窗无报错。

### S3 分析（1:20–2:20）

1. 进入“分析中心 → 分析运行”，确认当前无 RUNNING 记录。
2. 选择“全量运行”，点击“开始分析”；等待状态变为“成功”。
3. 读出项目数、对数、耗时（60 项目约 1.5 秒，视机器而定）。
4. 回到项目详情，切到“重复度”页签。
5. 展开 Top-1 相似项目，展示分维度得分、重复点与差异点。
6. 预期：有 HIGH 等级项目对；无控制台报错。
7. 注意：若已有运行记录，可直接展示历史成功记录，避免等待。

### S4 趋势（2:20–3:20）

1. 进入“趋势与归因”，确认时间范围为近 12–14 个月。
2. 切换粒度“月 → 季”再切回“月”，展示图表联动。
3. 项目组筛选选择“智能计算项目组”，展示指标变化。
4. 指向四类归因图例与堆叠柱，停留 3 秒。
5. 滚动到热力图，悬浮一个单元格显示样本数。
6. 点击任一月度数据点，进入下钻项目清单，再点开一个项目对。
7. 预期：URL 带筛选条件；下钻列表非空。

### S5 投入与决策（3:20–4:05）

1. 进入“投入态势”，展示 KPI 卡与风险敞口。
2. 切换到“按项目组”，展示分布。
3. 进入“辅助决策”，选择同一项目，点击预检。
4. 展示风险分、等级、Top-5 相似项目、建议动作、预计重复投入、建议专家。
5. 停留 3 秒，让观众看清建议动作与金额。
6. 预期：结果与项目重复度报告一致。

### S6 治理与报告（4:05–4:45）

1. 退出 admin，使用 `expert01 / Expert@12345` 登录。
2. 进入“评审任务”，打开一个 REVIEWING 项目，填写评分 90、意见“内容与存量项目差异明确”、结论 PASS，提交。
3. 退出，使用 `pmo01 / Pmo@12345` 登录。
4. 打开该项目详情，展示“专家评审”页签与“审批轨迹”，执行“确认立项”。
5. 进入“决策记录”，打开一条记录详情，点击导出 Word；下载完成后打开文件停留 3 秒。
6. 预期：PASS 数达标后可立项；报告包含相似项目与口径说明。
7. 注意：若该项目 PASS 数不足，先切换到 `expert02 / Expert2@12345` 再提交一次 PASS。

### S7 收尾（4:45–5:00）

1. 切换回工作台或 README 页面。
2. 停留 3 秒，鼠标移到版本信息。
3. 预期：无报错，画面稳定。

## 3 录制风险与备用方案

| 风险 | 现象 | 备用方案 |
|------|------|----------|
| 后端未启动 | 登录页报网络错误 | 先执行 stop-demo 再 start-demo -SkipBuild |
| 前端未启动 | 5173 无法访问 | start-demo 会自动启动 Vite；或手动 npm run dev |
| 趋势无数据 | 趋势页为空 | 执行 scripts/backfill-trend.ps1 -Months 14 |
| 分析耗时过长 | 等待超过 10 秒 | 直接展示历史成功运行，跳过等待 |
| PASS 数不足 | 无法立项 | 用 expert02/03 补足 PASS |
| 报告下载被拦截 | 浏览器提示 | 允许下载后重新点击，或改用决策记录详情页链接 |
| 模型未配置 | 无“模型复核”内容 | 视频不依赖模型；如需展示，先配置环境变量并在分析配置开启 |
