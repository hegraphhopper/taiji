## 2 画面节奏

- 每页 15–30 秒；前 0.3 秒淡入，结束前 0.35 秒淡出。
- 画面缓慢推近（缩放 1.00 → 1.05），避免长时间静止。
- 字幕每句 4.6 秒，句间留白；提示条整段显示，两端淡入淡出。
- 页面切换为硬切，不做转场，避免注意力分散。

## 3 重新生成

1. 修改 `_build/timeline.json` 中的画面、时长、提示与字幕。
2. 在项目根目录执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File docs/review/video/_build/make-video.ps1
```

3. 脚本会重新生成 `demo.ass`、`demo.srt`、TTS 与 `演示视频.mp4`。
4. 需要替换画面时，覆盖 `slides/` 下同名 PNG（保持 1440×900）。

## 4 素材替换建议

| 场景 | 建议替换为 |
|------|------------|
| 登录页 | 当前版本登录页（含演示账号提示） |
| 项目列表 | 筛选了“智能计算项目组”的列表 |
| 重复度报告 | 打开 Top-1 相似项目后的明细 |
| 趋势 | 选中某月度数据点后的下钻状态 |
| 辅助决策 | 已有预检结果的页面 |
| 评审任务 | 评审弹窗打开状态 |

替换后无需改脚本，只要文件名与尺寸一致；字幕时间如需同步调整，改 `timeline.json` 后重跑。
