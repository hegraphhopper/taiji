# 演示视频录制指南

## 0 目标与约定

- 成片时长 5:00，分辨率 1440×900（或等比例 1920×1200），30 fps，MP4（H.264）。
- 必须有中文字幕（SRT 烧录或外挂），并按 `overlay-hints.md` 叠加屏幕提示条。
- 口播使用 `narration.md`，字幕使用 `demo.srt`，画面按 `storyboard.md`。
- 本机未安装 ffmpeg，字幕建议在剪映专业版中导入并烧录；不依赖命令行。

## 1 录制前环境准备

### 1.1 启动系统

在项目根目录执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/stop-demo.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/start-demo.ps1 -SkipBuild
```

- `-SkipBuild` 使用已有 jar，启动更快；若 jar 不存在，去掉该参数。
- 等待脚本输出访问地址；健康检查：`http://localhost:8080/api/v1/health`。
- 前端：`http://127.0.0.1:5173`。
- 若端口被占用，先执行 stop-demo，再启动。

### 1.2 数据基线检查

- 项目列表总数应为 60（`DEMO-001`–`DEMO-060`）。
- 趋势页应有 12 个月以上数据点；不足时执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/backfill-trend.ps1 -Months 14
```

- 若数据异常，可停止服务后删除 `data/` 目录再启动，系统会按 Flyway 与演示数据初始化重建。
- 大模型默认关闭，视频不依赖外部接口；如需展示“模型复核”，先配置 `LLM_ENABLED/LLM_BASE_URL/LLM_MODEL/LLM_API_KEY`，并在分析配置页开启。

## 2 录屏设置

### 2.1 画面

- 浏览器窗口 1440×900，缩放 100%，隐藏书签栏（Ctrl+Shift+B）。
- 关闭无关通知、聊天软件与系统弹窗；桌面背景纯色。
- 使用浏览器无痕窗口，避免账号自动填充与历史记录干扰。

### 2.2 录制工具

推荐 OBS Studio：

| 项 | 设置 |
|----|------|
| 画布分辨率 | 1440×900 |
| 输出分辨率 | 1440×900 |
| 帧率 | 30 fps |
| 编码 | H.264，CBR 6000 Kbps |
| 音频 | 48 kHz，麦克风降噪开启 |
| 格式 | MP4 |

备选：Windows 自带录屏（Win+G），导出后仍需在剪映中加字幕与提示条。

### 2.3 录音

- 使用耳机麦克风，关闭外放，避免回声。
- 先录 10 秒环境噪声，便于降噪。
- 按段落分段录制（S1–S7），每段保留 2 秒余量，便于剪辑。

## 3 剪辑与字幕

### 3.1 导入

1. 新建剪映草稿，比例 16:9，分辨率 1440×900 或 1920×1080。
2. 导入分段录屏，按 `storyboard.md` 顺序拼接，总时长裁到 5:00。
3. 导入口播音频（如与画面同录则跳过）。

### 3.2 字幕

1. 剪映：`文本 → 智能字幕 → 导入本地字幕`，选择 `demo.srt`。
2. 检查断行：每行不超过 18 个汉字；必要时手动合并或拆分。
3. 样式：微软雅黑 / 思源黑体，28–32 px，白色，3 px 黑描边，底部居中。
4. 逐条校对与口播是否一致，重点核对数字：30 天、40/60/80 分、Top-5、60 项目。

### 3.3 提示条

1. 用剪映“文字”或“贴纸”制作提示条，背景 `#1F2D3D` 85% 透明，白字 20–24 px。
2. 按 `overlay-hints.md` 的时间码放置，每条 3–5 秒，淡入淡出 0.2 秒。
3. 高亮框用矩形描边（`#409EFF`，2 px），箭头仅在两处使用。

### 3.4 导出

| 项 | 设置 |
|----|------|
| 分辨率 | 1440×900 或 1920×1080 |
| 帧率 | 30 fps |
| 码率 | 推荐 8–10 Mbps |
| 编码 | H.264 |
| 音频 | AAC 192 Kbps |
| 格式 | MP4 |
| 字幕 | 烧录进画面（同时保留 SRT 源文件） |

## 4 录制顺序建议

1. 先录 S3（分析）与 S4（趋势），确认数据正确。
2. 再录 S2（申报）、S5（投入与决策）。
3. 然后录 S6（评审、立项、导出），需要切换三个账号。
4. 最后录 S1、S7，语速与停顿更容易控制。
5. 全片回放一遍，确认无密码、Token、真实个人信息入镜。

## 5 质量检查清单

- [ ] 总时长 4:50–5:10，画面无黑屏、无卡顿。
- [ ] 字幕与口播逐句一致，无错别字，数字正确。
- [ ] 提示条与操作步骤对应，不遮挡关键按钮。
- [ ] 登录、分析、趋势、预检、评审、导出六个关键动作完整可见。
- [ ] 未出现浏览器密码保存弹窗、系统通知、其他账号信息。
- [ ] 未出现真实密钥、Token、内网地址。
- [ ] 导出文件可正常播放，声音与画面同步。
- [ ] 同时保留 `demo.srt` 与 `narration.md`，便于后续改版。

## 6 常见问题

| 问题 | 处理 |
|------|------|
| 5173 打不开 | 确认 start-demo 已启动 Vite；或 `cd frontend; npm run dev` |
| 登录后立即回登录页 | 检查后端健康与 `JWT_SECRET` 是否重启变化；退出后重登 |
| H2 数据库被锁 | 确认只有一个后端进程占用 `data/`，执行 stop-demo 后重启 |
| 趋势为空 | 执行 backfill-trend.ps1 -Months 14 |
| 无法立项 | 用 expert02/03 补足 PASS 票数（默认需要 2 位不同专家） |
| 字幕乱码 | 确认 SRT 为 UTF-8；剪映导入时选择 UTF-8 |
| 录音有回声 | 戴耳机、关闭外放，重新录制该段 |
