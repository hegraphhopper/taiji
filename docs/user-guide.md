# 用户手册

## 1. 启动与登录

1. 执行 `powershell -ExecutionPolicy Bypass -File scripts/start-demo.ps1 -SkipBuild`。
2. 打开 `http://127.0.0.1:5173`。
3. 演示账号：

| 账号 | 密码 | 角色 |
|------|------|------|
| `admin` | `Admin@123` | 系统管理员 |
| `pmo01` | `Pmo@12345` | 基金办 |
| `user01` | `User@12345` | 项目组用户（智能计算组） |
| `expert01` | `Expert@12345` | 评审专家 |
| `expert02/03` | `Expert2@12345` / `Expert3@12345` | 评审专家 |

首次登录建议修改密码；演示账号仅用于本地演示。

## 2. 项目组用户

- 项目管理 → 新建项目：填写名称、编码、基金类型、技术方向、预算、起止日期。
- 项目详情 → 申报内容/节点与成员：维护目标、研制内容、关键技术、节点、成员。
- 附件：上传 docx/pdf/md → 解析 → 检查回填结果 → 保存。
- 提交前校验预算、起止日期、至少 1 目标/1 内容/1 节点。
- 提交后可撤回；被驳回后修改并重新提交。
- 待办中心：查看草稿/被驳回/待执行/待结项。
- 辅助决策：选择项目预检，查看重复度、Top 相似项目、建议动作与模型复核。

## 3. 基金办

- 项目管理：查看全所项目，按状态/组/基金/技术方向筛选。
- 形式审查：已提交项目 ACCEPT → 评审中；REJECT 需填写意见。
- 立项：评审中项目在专家 PASS 数达标后 APPROVE；可 TERMINATE。
- 分析中心：触发全量/单项目分析，查看运行记录、模型开关与权重。
- 趋势与归因、投入态势、决策记录、报告导出。

## 4. 评审专家

- 评审任务：仅显示评审中且本人本轮未提交的项目。
- 提交评审：评分 0–100、意见、结论 PASS/REJECT/REVISE；每轮每人一次，提交后不可修改。
- 项目详情：查看重复度报告与模型复核理由；不可编辑项目、不可看趋势/投入/系统管理。

## 5. 系统管理员

- 用户管理：新增/编辑/启停/重置密码/分配角色；禁用后旧 token 立即失效。
- 组织与字典：项目组、技术方向树形维护；被引用时不可删除。
- 角色与权限：查看固定角色与权限点。
- 系统参数：`review.requiredPassCount`（1–10，默认 2）。
- 分析配置：字段权重、阈值、Top-K、大模型开关/权重/超时；“测试连接”验证模型。
- 模型调用日志：查看调用状态、耗时、Token 与错误，不包含 Prompt/Key。
- 审计日志：条件查询、详情、CSV 导出；仅管理员可见。

## 6. 常见问题

- **端口占用**：先执行 `scripts/stop-demo.ps1`。
- **H2 锁**：不要同时启动两个后端指向同一 `data/`。
- **大模型未生效**：检查 `LLM_ENABLED/LLM_BASE_URL/LLM_MODEL/LLM_API_KEY`，并在分析配置页开启；点击“测试连接”。
- **趋势无数据**：执行分析运行或 `scripts/backfill-trend.ps1 -Months 14`。
