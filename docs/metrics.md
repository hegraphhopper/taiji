# 指标口径

## 1. 重复度

字段权重默认：

| 维度 | 权重 |
|------|------|
| 项目目标 | 15 |
| 研制内容 | 35 |
| 关键技术 | 35 |
| 节点计划 | 5 |
| 技术标签 | 10 |

单维度相似度由中文分词 + TF-IDF 余弦计算；本地总分 = 各维度加权平均（0–100）。

## 2. 等级

| 等级 | 分数 |
|------|------|
| HIGH | ≥ 80 |
| MEDIUM | 60–79.99 |
| LOW | 40–59.99 |
| NONE | < 40 |

阈值可在分析配置中调整；高风险对为 `level=HIGH` 的项目对。

## 3. 归因

| 归因 | 判定 |
|------|------|
| `SELF_GROUP` | 同项目组 |
| `PEER_EARLIER` | 跨组，对方提交更早 |
| `OUR_EARLIER` | 跨组，我方提交更早 |
| `SIMULTANEOUS` | 跨组，提交时间相差 ≤ 30 天 |

展示时按当前查看项目翻转方向。

## 4. 趋势与快照

- 每个 `analysisDate` 生成一条 `duplicate_snapshot`。
- 月度指标：平均最高重复度、高风险项目数、高风险对数、四类归因计数、风险敞口。
- 历史回填只写快照，不回写项目当前分数；最新一次正式运行更新项目分数。

## 5. 风险敞口

```text
风险敞口 = Σ(高风险项目预算 × 最高重复度 / 100)
```

预检预计重复投入 = 预算 × Top-1 重复度 / 100（保留 2 位）。

## 6. 预检建议

规则按优先级升序、首个命中；未命中回退 `EXPLAIN`：

- 高重复 → `MERGE` / `TERMINATE`
- 中低重复 → `EXPLAIN`
- 无重复 → `APPROVE`

## 7. 大模型解释

- 默认关闭；仅对本地分 Top-N 候选调用。
- 输出 `semanticScore/overlaps/differences/suggestion/reason`，严格 JSON 校验。
- 解释层模式 `localWeight=100 / llmWeight=0`：总分不变，只展示模型复核理由/重复点/差异点。
- 失败、超时、未配置：`llmUsed=false`，沿用本地结果。

## 8. 立项 PASS 门禁

统计项目全部轮次中 `result=PASS` 的不同专家数；同一专家多轮 PASS 只计 1 人；达到 `review.requiredPassCount`（默认 2）才允许 `REVIEWING → APPROVED`。
