# 5 分钟演示脚本

## 0:00–0:30 问题与目标

- 画面：登录后工作台。
- 台词：自投项目逐年增多，同一方向重复立项、跨组近似投入、同期并行难以人工发现。平台把申报书结构化，量化重复度并解释原因。

## 0:30–1:15 申报书结构化与解析

- 画面：项目管理 → 项目详情 → 申报内容/附件。
- 操作：展示目标、研制内容、关键技术、节点、成员；上传 docx 并解析回填。
- 台词：结构化字段既服务人工审核，也是后续重复度分析的输入。

## 1:15–2:15 重复度分析与解释

- 画面：项目详情 → 重复度页签；分析中心运行记录。
- 操作：打开 Top 相似项目，展开重复点/差异点；如启用模型，展示“模型复核”理由。
- 台词：分数由五维加权本地算法计算；模型只做解释，不改变总分与趋势。

## 2:15–3:15 趋势与归因（重点）

- 画面：趋势与归因。
- 操作：切换月份、项目组；查看四类归因（同组/他方在先/我方在先/同期）、热力图、下钻。
- 台词：不仅看“现在重复多少”，还看重复如何随时间累积、集中在哪些组和方向。

## 3:15–4:00 投入态势与辅助决策

- 画面：投入态势 → 辅助决策。
- 操作：查看风险敞口、Top 高风险项目；对新项目预检，展示风险分、建议动作、预计重复投入、建议专家。
- 台词：把重复度翻译成预算风险，给出合并/说明/通过/终止建议。

## 4:00–4:40 审批治理与报告

- 画面：评审任务 → 审批轨迹 → 决策记录导出。
- 操作：专家评分/结论；PMO 立项；导出 Word/Excel（含模型复核段）。
- 台词：权限、数据范围、评审与审批全程留痕，报告可离线评审。

## 4:40–5:00 技术与交付

- 画面：README/部署说明。
- 台词：Spring Boot 2.7 + Vue 3 + H2/MySQL；本地一键启动，Docker/WeCode 可选；全量测试与构建通过。
