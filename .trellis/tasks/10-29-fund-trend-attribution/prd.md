# 重复度趋势与归因看板（PRD）

## Goal

项目管理人员登录后，能直接看到所申报项目重复度随时间的变化趋势，并判断问题主要来自**本组内部重复**、**他组在先（我方撞他组）**、**我方在先（他组撞我方）**还是**同期并行**，从而把治理动作落到具体项目组、技术方向与项目对。

## 范围

- 趋势查询：月度/季度，平均重复度、最高分、高风险项目数、分析项目数、项目对数。
- 归因查询：四类归因计数与占比，按时间/项目组/技术方向/基金类型筛选。
- 热力图：项目组 × 月份（平均重复度或高风险数）、技术方向 × 项目组。
- 下钻：趋势点 → 项目列表 → 项目对明细 → 重复/差异片段。
- 结论摘要：规则化文字（上升/下降、主要归因、重点关注组）。
- 导出：趋势与归因 CSV。
- 不做：原始分析计算（engine）、投入金额（investment）、决策建议（decision）。

## 功能需求

### F1 趋势指标

- 时间粒度：`MONTH`（默认）/`QUARTER`/`YEAR`。
- 每个时间点返回：
  - `analyzedProjectCount`：当月有快照的项目数（同项目同月取最新 run，只计 1 次）。
  - `avgMaxScore`：快照 `max_score` 平均值。
  - `avgTopScore`：快照 `avg_top_score` 平均值。
  - `highRiskCount`：当月 `high_pair_count > 0` 的项目数（按分析当时的阈值判定，不随配置调整回改历史）。
  - `pairCount`：项目视角对数 = Σ(`self_group_count + cross_group_count`)。
  - `uniquePairCount`：当期唯一项目对数（无序对去重）。
  - `highPairCount`：Σ `high_pair_count`（项目视角）。
  - 四类归因计数与占比（基于项目快照计数，按查看项目视角）。
- 环比：与上一时间点比较的变化值与百分比；首点返回 `null`。
- 空数据：返回空数组与 `hasData=false`，前端显示空态。

### F2 归因

- 四类：`SELF_GROUP`、`PEER_EARLIER`、`OUR_EARLIER`、`SIMULTANEOUS`。
- 支持按时间范围、项目组、技术方向、基金类型、等级过滤。
- 输出总数、各类计数、占比、环比变化。
- 提供“按项目组拆分的归因矩阵”，用于识别哪个组的跨组撞车最突出。
- 归因计数按**项目视角**：跨组对在双方项目下各计一次（与项目详情页快照数字一致）；`uniquePairCount` 另列，回答"所里到底有多少对重复"。页面、tooltip、CSV 均注明该口径。
- `level` 筛选不进入趋势顶部筛选条（与"按当时阈值判定"冲突），仅用于下钻项目列表与项目对明细。

### F3 热力图

- 维度一：行=项目组，列=月份，值=平均最高重复度/高风险项目数（可切换）。
- 维度二：行=技术方向，列=项目组，值=平均最高重复度/高风险项目数。
- 无数据单元格显示浅灰；值分档着色；tooltip 显示样本数与下钻入口。

### F4 下钻

- 点击趋势点 → 抽屉/弹窗：该时间点、该筛选条件下的项目列表（名称、组、方向、最高分、等级、归因数）。
- 点击项目 → 复用项目报告接口，展示 Top-K 相似项目与片段。
- 点击项目对 → 展示双方信息、分维度分、重复点、差异点、LLM 理由（若有）。
- 下钻条件写入 URL query，刷新/分享后保持。

### F5 结论摘要

- 规则生成 3–5 句：
  - 本期平均最高重复度较上期上升/下降 X%。
  - 主要归因是“本组内部”/“他组在先”/“我方在先”/“同期并行”，占比 X%。
  - 重点关注项目组：Top 2（高风险数或跨组重复最多）。
  - 建议动作：对高风险项目对发起差异说明或合并评估（只给方向，不下结论）。
- 摘要中的数字必须与图表一致；无数据时提示“暂无可分析数据”。

### F6 权限与数据范围

- `PMO/ADMIN`：全所数据，可按任意项目组筛选。
- `GROUP_USER`：强制限定本组，项目组筛选禁用或仅本组。
- `EXPERT`：趋势看板不可见（菜单不展示，接口 403）。
- 导出遵循同一数据范围。

## 验收标准

- [ ] 内置演示数据下，趋势图至少展示 6 个月数据点，指标与数据库快照复算一致。
- [ ] 同项目同月多次分析只计一次，取当月最新 run；跨月保留历史。
- [ ] 四类归因计数之和等于同期**项目视角对数**（过滤后），且等于页面 `pairCount`；`uniquePairCount ≤ pairCount`；占比合计 100%（允许四舍五入误差）。
- [ ] `highRiskCount` 等于 `high_pair_count > 0` 的项目数；调整阈值后历史月份数值不变。
- [ ] 筛选项目组/技术方向/基金类型/时间范围后，趋势、归因、热力图三者联动一致。
- [ ] 项目组用户仅看到本组数据；切换他组参数被忽略或返回 403（按接口约定一致）。
- [ ] 点击趋势点可下钻到项目列表，再进入项目对明细，URL 可复现。
- [ ] 热力图两种维度切换正常，无数据单元格与 tooltip 正确。
- [ ] 结论摘要数字与图表一致；无数据时显示空态而非报错。
- [ ] CSV 导出内容与当前筛选一致，含口径说明与生成时间。
- [ ] 图表在 1440×900 与 1280×800 下不重叠、不溢出；控制台无错误。
- [ ] 后端聚合单测覆盖月份去重、归因边界、空数据；`npm run build` 通过。

## 依赖与约束

- 前置：dup-engine（快照、项目对、配置阈值）。
- 只读分析结果，不重新计算相似度。
- 归因按“查看项目”视角；同一对在两个项目下分别计数（趋势按项目维度统计），跨组对在双方项目组各出现一次属预期，文档需说明口径。
- 月份以服务器时区 `Asia/Shanghai` 计算。
