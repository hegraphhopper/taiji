# 大模型能力扩展 — PRD

## Goal

在不改变现有本地重复度分数与趋势口径的前提下，启用大模型作为“解释层”，补齐连接自检、决策预检模型复核、重复/差异点落库与报告模型复核段。

## 范围

- LLM 解释层：`localWeight=100 / llmWeight=0`，总分与趋势不变。
- 连接自检：管理员可测试当前模型配置。
- 决策预检：Top-1 相似对调用模型，返回复核理由；失败降级。
- 重复/差异点：`analysis_pair` 新增 `llm_overlaps`、`llm_differences` 并展示。
- 报告：Word/Excel 决策报告新增“大模型复核”段。

## 不做

- 模型训练/微调、多供应商管理、Prompt 编辑器、异步批处理、成本计费。

## 验收标准

- [x] 管理员测试连接成功/失败均有明确结果，响应不含 API Key。
- [x] 开启 LLM 后分析运行 `llmUsed=true`，总分与关闭时一致。
- [x] 决策预检返回 `llmUsed/llmReason`，风险分与规则建议不变；失败自动降级。
- [x] 重复/差异点落库并在项目详情展示；旧数据空态正常。
- [x] Word/Excel 报告包含“大模型复核”段；未启用时标注本地算法结果。
- [x] `mvn test`、`npm run typecheck`、`npm run build` 通过。

## 约束

- Key/BaseURL/Model 由环境变量注入，不落库、不回显、不写日志。
- 模型失败不得阻断分析、预检或导出。
