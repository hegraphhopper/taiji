# 大模型能力扩展 — 用例设计

## 用例设计摘要

- 被测范围：模型连接自检、分析解释落库、预检 Top-1 解释、报告复核段、降级。
- 口径：LLM 只做解释层，不改变 `totalScore`、趋势与规则建议。
- 栈：JUnit 5 + MockMvc + H2；前端 typecheck/build。

## 单元用例

### UT-L01 连接自检成功
- 关联验收：第 1 条
- 被测对象：`POST /api/v1/system/llm/test`
- 前置：ADMIN，`app.llm.enabled=true`，mock 返回合法 JSON
- 预期：200，`success=true`，含 latency/model，不含 apiKey
- 优先级：P0

### UT-L02 连接自检失败与权限
- 关联验收：第 1 条
- 前置：mock 返回超时/HTTP 错误；PMO 调用
- 预期：ADMIN 返回失败状态与错误摘要；PMO 403
- 优先级：P0

### UT-L03 分析解释落库
- 关联验收：第 2、4 条
- 被测对象：`AnalysisExecutor` / `analysis_pair`
- 前置：LLM 开启，mock 返回 overlaps/differences
- 预期：`llmUsed=true`；`llm_score/llm_reason/llm_overlaps/llm_differences` 入库；`total_score` 与纯本地一致
- 优先级：P0

### UT-L04 预检 Top-1 解释
- 关联验收：第 3 条
- 被测对象：`AnalysisExecutor.precheck` / `DecisionPrecheckService`
- 前置：LLM 开启，项目存在 Top-1 相似对
- 预期：`llmUsed=true`，Top-1 含 `llmReason`；`riskScore` 等于本地 Top-1 总分；`recommendation` 不变
- 优先级：P0

### UT-L05 预检降级
- 关联验收：第 3 条
- 前置：LLM 返回失败/未配置
- 预期：`llmUsed=false`；预检仍成功，风险分与规则建议正常
- 优先级：P0

### UT-L06 报告复核段
- 关联验收：第 5 条
- 被测对象：`DecisionWordReportBuilder` / `DecisionExcelReportBuilder`
- 前置：记录含 `llmReason/llmOverlaps/llmDifferences`
- 预期：Word 含“大模型复核”；Excel 含复核 Sheet；无数据时含“本地算法结果”
- 优先级：P0

### UT-L07 前端展示
- 关联验收：第 4、5 条
- 被测对象：项目详情重复度、决策预检、分析配置
- 预期：模型理由/重复点/差异点可见；测试连接按钮可用；`npm run build` 通过
- 优先级：P1
