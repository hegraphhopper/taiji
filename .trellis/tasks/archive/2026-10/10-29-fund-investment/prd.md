# 技术创新投入态势分析（PRD）

## Goal

把自投项目的资金、数量、技术方向与重复度放在同一视图，回答“钱投到哪里、投得是否集中、重复投入风险有多大”，为基金办优化投入结构提供数据依据。

## 范围

- 投入概览 KPI、按年度/基金类型/项目组/技术方向的分布与趋势。
- 重复投入风险敞口与高风险敞口。
- 技术方向热度、组间对比、重复度-投入散点。
- 下钻项目列表与 Excel/CSV 导出。
- 不做：财务凭证、决算、工时成本、重复度计算（读取已有结果）。

## 实施口径锁定（B1 开工前确认）

- 未分析项目：`unanalyzedCount` 单列，**不计入平均最高重复度分母**。
- 年份维度：`start_date` 所在年度；缺失回退 `created_at`。
- 状态范围：`APPROVED / IN_PROGRESS / COMPLETED`，`includeCompleted=false` 排除结项。
- 重复度：取该项目最新快照（`analysis_date` 最新，同日取 `runId` 最大）。
- 高风险：`max_score >= 当前配置 high`；敞口按预算 × 最高分 / 100，保留 2 位。
- 同比：筛选范围内最新年度与上一年度比较；上一年无数据返回 null。
- 权限沿用 A4：PMO/ADMIN 全量、GROUP_USER 强制本组、EXPERT 403。
## 功能需求

### F1 统计口径

- 纳入状态：`APPROVED`、`IN_PROGRESS`、`COMPLETED`；`includeCompleted=false` 时可排除结项。
- 金额取 `project.budget`；项目数按项目去重；重复度取该项目**最新有效快照**的 `max_score`（无快照视为 0 并标记“未分析”）。
- 时间维度按 `start_date` 所在年度；无 `start_date` 时按创建时间。
- 所有指标在页面提供 `?` 说明，导出文件附口径。

### F2 概览 KPI

- 投入总额、项目数、在研项目数、已结项数。
- 平均预算、平均最高重复度、高风险项目数。
- 重复投入风险敞口：`Σ(预算 × max_score/100)`；高风险敞口：仅 `max_score ≥ high` 的项目。
- 同比：投入总额、项目数相对上一年度的变化率；无上一年数据返回 `null`。

### F3 多维分布

- 按年度：投入额、项目数、平均重复度（堆叠柱/组合图）。
- 按基金类型：平台基金/创新基金/其他的金额与项目数占比。
- 按项目组：投入额、项目数、风险敞口、平均重复度（排序对比）。
- 按技术方向：Top 10 投入额；矩形树图或横向条形；同时展示高风险项目数。
- 重复度-投入散点：x=预算，y=最高重复度，气泡大小=预算，颜色=风险等级；点击下钻项目。

### F4 风险敞口

- 按项目组、技术方向分解风险敞口，突出“高投入 + 高重复”象限。
- 表格列出 Top 10 高风险敞口项目（名称、组、预算、最高分、敞口金额、状态）。
- 敞口金额与项目明细可复算；四舍五入到元。

### F5 筛选与下钻

- 筛选：时间范围、基金类型、项目组、技术方向、是否含结项。
- `GROUP_USER` 仅本组；`PMO/ADMIN` 全部；`EXPERT` 不可见。
- 点击图表元素进入项目列表抽屉；项目可跳转详情与重复度报告。
- 筛选条件写入 URL。

### F6 导出

- Excel：KPI、年度分布、项目组分布、技术方向分布、Top 风险项目、口径说明。
- CSV：至少年度与技术方向两张表（或分文件）。
- 文件名含时间范围与生成时间。

## 验收标准

- [x] 概览 KPI 与数据库明细复算一致（总额、项目数、平均分、高风险数、敞口）。
- [x] 风险敞口 = Σ(预算 × 最高分/100)，与 Top 项目明细求和一致（误差 ≤1 元）。
- [x] 年度/基金类型/项目组/技术方向四类分布切换正确；筛选联动。
- [x] 同比在无上一年数据时显示“—”，有数据时计算正确。
- [x] 未分析项目在图表与表格中有“未分析”标识，不计入平均分分母（或单列说明，口径固定）。
- [x] 项目组用户仅见本组；专家接口 403；筛选他组无效。
- [x] 散点点击可下钻到项目；URL 可复现。
- [x] Excel/CSV 可打开、中文无乱码、内容与页面一致。
- [x] 空数据/单季度数据不报错，显示空态。
- [x] 后端指标单测与 `npm run build` 通过。

## 依赖与约束

- 前置：declaration（预算/状态/日期）、dup-engine（快照分数）。
- 只读聚合，不修改分析结果。
- 金额单位：元；展示时可按万元换算，但接口返回元，避免精度歧义。
