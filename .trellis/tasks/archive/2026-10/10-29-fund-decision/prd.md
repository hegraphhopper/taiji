# 新项目辅助决策与报告导出（PRD）

## Goal

在项目申报与立项环节，为新项目给出“是否重复、和谁重复、差在哪、建议怎么办、可能浪费多少钱”的可执行结论，并留存决策记录与可归档报告。

## 范围

- 申报前预检：选择草稿项目、已有项目或粘贴文本。
- 风险评分、Top-5 相似项目、重复/差异点、建议动作、预计重复投入金额、建议评审专家。
- 决策规则配置（分数/归因 → 建议动作）。
- 决策记录留存与查询。
- Word 决策报告、Excel 相似项目明细导出。
- 不做：重新实现相似度（复用 engine 预检）、审批流（复用 declaration）、投入看板（引用 investment 口径）。

## 功能需求

### F1 预检入口

- `PROJECT`：选择已有项目（草稿/已提交），复用其结构化内容分析。
- `TEXT`：粘贴目标/研制内容/关键技术/节点计划，临时分析，不落项目。
- 预检不修改项目状态；`PROJECT` 模式下可更新该项目最新快照（配置 `updateSnapshot=true`，默认 false，避免草稿影响趋势）。
- 预检结果进入决策记录需用户确认“保存决策”。

### F2 预检结果

- 综合风险分（0–100）、等级（高/中/低/无明显重复）。
- Top-5 相似项目：名称、编码、项目组、负责人、状态、预算、总分、分维度分、归因（本组/他组在先/我方在先/同期）。
- 重复点：按维度列出重复关键词与原文片段。
- 差异点：列出本项目相对相似项目的新增/不同关键词与说明。
- 建议动作（规则优先）：
  - `APPROVE` 可立项：低重复或差异充分。
  - `EXPLAIN` 补充差异说明：中等重复。
  - `MERGE` 建议合并：高重复且同组或对方在先。
  - `TERMINATE` 建议终止/转向：高重复且重复点覆盖核心内容。
- 预计重复投入金额 = 预算 × 风险分 / 100；无预算时返回 `null` 并提示补充预算。
- 建议评审专家：同技术方向、启用、按进行中评审数升序取 3；不足时补充基金办。
- 理由：规则模板文字 + 可选大模型理由（若启用且成功）。

### F3 决策规则配置

- 规则表：优先级、条件（分数区间、归因类型、是否同组）、建议动作、说明。
- 默认规则（从高到低）：
  1. 分数 ≥80 且（同组 或 对方在先）→ `MERGE`。
  2. 分数 ≥90 → `TERMINATE`（核心高度重合）。
  3. 分数 ≥60 → `EXPLAIN`。
  4. 其他 → `APPROVE`。
- 管理员可编辑阈值与动作，保存后立即生效；变更写审计。
- 规则未命中时回退 `EXPLAIN` 并提示人工判断。

### F4 决策记录

- 保存：项目（可空）、预检运行 ID、风险分、等级、建议、理由、Top 相似项目 JSON、预计金额、操作人、时间。
- 查询：按项目、组、时间、建议、等级筛选；详情可回看当时的相似项目与理由。
- 记录不可编辑，只能作废（软删除 + 审计）；导出报告使用记录快照，避免数据变化导致结论漂移。

### F5 报告导出

- Word：
  - 标题、生成时间、项目基本信息。
  - 决策结论（等级、建议、理由、预计重复投入）。
  - Top-5 相似项目表（组、负责人、总分、归因）。
  - 重复点/差异点分维度列表。
  - 数据口径与免责说明（字面+语义算法，仅供决策参考）。
- Excel：相似项目明细 + 分维度分 + 片段。
- 文件可正常打开，中文不乱码；文件名含项目编码与日期。
- 导出动作写审计。

### F6 权限

- `GROUP_USER`：可对本组草稿预检、保存/查看本组记录、导出。
- `PMO/ADMIN`：全部项目预检、全部记录、导出。
- `EXPERT`：只读查看被评审项目的预检结果，不可保存/导出（或允许导出报告，默认允许只读导出）。
- 临时文本预检结果不落项目，但保存记录时记录操作人与文本摘要 hash。

## 验收标准

- [x] 选择高重复夹具项目预检：等级高，Top-1 为预期相似项目，建议为 `MERGE` 或 `TERMINATE`，重复点含关键术语。
- [x] 中等重复：建议 `EXPLAIN`；低重复：建议 `APPROVE`；规则调整后建议随之变化。
- [x] 预计重复投入金额 = 预算 × 风险分 / 100（±1 元），无预算时为空并提示。
- [x] 建议专家来自同技术方向，数量 ≤3；无匹配时回退基金办。
- [x] 大模型关闭/失败时仍返回完整规则结论，理由标注“本地算法”。
- [x] 保存决策后可在记录列表查询并在详情回看；记录不可编辑。
- [x] Word 报告包含全部章节且中文正常；Excel 明细与页面一致；文件名规范。
- [x] 项目组用户不能预检/导出他组项目；专家不可保存记录。
- [x] 预检不改变项目状态；`updateSnapshot=false` 时趋势不受影响。
- [x] `mvn test` 覆盖规则映射、金额计算、报告生成、降级；`npm run build` 通过。

## 依赖与约束

- 前置：dup-engine（预检能力、相似对）、declaration（项目/预算/技术方向）、foundation（用户/角色）。
- 规则动作是建议，不自动改变项目状态；最终由 PMO 决策。
- 报告内容仅基于系统数据，不引入外部未授权内容。
