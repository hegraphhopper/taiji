# helloworld 主程序 — 用例设计

## 用例设计摘要

- 被测范围：`com.example.helloworld.HelloWorld` 的 `main` 行为，以及 Maven 工程的构建产物。
- 本轮按用户决定不编写自动化单元测试，用例以命令行方式验证（编译、运行、产物检查），预期结果均为可断言的字符串或文件存在性。
- 优先级：P0 为构建成功与输出正确；P1 为构件坐标与产物名；P2 为 `.gitignore` 覆盖范围。

## 单元用例

### UT-01 主程序输出 Hello, World!
- 关联需求/AC：AC5
- 被测对象：`src/main/java/com/example/helloworld/HelloWorld.java` 的 `public static void main(String[])`
- 前置条件：已执行 `mvn -q clean package`，`target/classes` 存在
- 输入：无命令行参数
- 步骤：1. `java -cp target/classes com.example.helloworld.HelloWorld` 2. 捕获标准输出
- 预期结果：标准输出恰为一行 `Hello, World!`，进程退出码 0
- 优先级：P0

### UT-02 Maven 构建成功并产出 jar
- 关联需求/AC：AC1、AC2、AC4
- 被测对象：`pom.xml` 与 `src/main/java` 源码树
- 前置条件：Maven 3.5.0 + JDK 1.8.0_65 可用；首次构建需联网获取插件
- 输入：`mvn -q clean package`
- 步骤：1. 执行构建命令 2. 检查退出码 3. 检查 `target/helloworld-1.0.0.jar`
- 预期结果：命令退出码 0；`target/helloworld-1.0.0.jar` 存在
- 优先级：P0

### UT-03 编译目标为 Java 8
- 关联需求/AC：AC1
- 被测对象：`pom.xml` 的 `maven.compiler.source/target` 与 `maven-compiler-plugin` 配置
- 前置条件：`pom.xml` 已存在
- 输入：无
- 步骤：1. 读取 `pom.xml` 2. 校验 `source`/`target` 为 `1.8`、插件版本为 `3.8.1`
- 预期结果：两个属性值均为 `1.8`，编译器插件版本为 `3.8.1`
- 优先级：P1

### UT-04 边界：无参数与多余参数均不影响输出
- 关联需求/AC：AC5
- 被测对象：`HelloWorld.main`
- 前置条件：同 UT-01
- 输入：`java -cp target/classes com.example.helloworld.HelloWorld foo bar`
- 步骤：1. 带两个无关参数运行 2. 捕获标准输出
- 预期结果：仍输出恰为 `Hello, World!`，不抛异常
- 优先级：P2

### UT-05 .gitignore 覆盖构建产物
- 关联需求/AC：AC3
- 被测对象：仓库根 `.gitignore`
- 前置条件：构建已生成 `target/`
- 输入：`git status --porcelain --ignored`
- 步骤：1. 检查 `.gitignore` 含 `target/` 2. 检查 `git status` 不把 `target/` 列为待提交
- 预期结果：`.gitignore` 含 `target/`；`target/` 不出现在未跟踪文件列表中
- 优先级：P2

| AC4 mvn clean package 产出 jar | UT-02 |
