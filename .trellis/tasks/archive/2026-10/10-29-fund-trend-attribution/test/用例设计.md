# A4 重复度趋势与归因 — 用例设计

## 用例设计摘要

- 被测范围：趋势聚合与月份去重、四类归因（项目视角）、唯一对数、热力图两种维度、结论摘要、下钻项目列表、CSV 导出、权限与数据范围、前端筛选联动与 URL 复现。
- 测试环境：Spring Boot Test + H2 内存库 + MockMvc；快照/项目对数据直接经 Mapper 造数，避免依赖 A3 运行耗时不稳。
- 口径基线（A4 锁定）：归因按项目视角（跨组双方各计一次）；`highRiskCount = high_pair_count > 0` 的项目数；`uniquePairCount` 为无序对去重。
- 优先级：P0 覆盖去重、聚合、归因、权限、口径一致性；P1 覆盖热力、摘要、下钻、CSV；P2 覆盖边界与性能。

## 单元用例

### UT-01 同项目同月多次分析只取最新 run
- 关联需求/AC：F1；验收第 2 条
- 被测对象：`TrendQueryService.monthDedup`
- 前置条件：项目 P1 在 2026-05 有 run=3、run=7 两条快照，maxScore 分别为 50、72
- 输入：`startMonth=2026-05&endMonth=2026-05`
- 步骤：1. 查询趋势 2. 取 2026-05 点
- 预期结果：`analyzedProjectCount=1`；`avgMaxScore=72`；只采用 run=7；run=3 的指标不参与
- 优先级：P0

### UT-02 跨月各自保留
- 关联需求/AC：F1
- 被测对象：`TrendQueryService`
- 前置条件：P1 在 2026-04、2026-05 各有快照
- 输入：`2026-04..2026-05`
- 步骤：查询
- 预期结果：返回 2 个时间点，点数与月份数一致；不存在为空月份补 0 的行为（按实现约定：无数据月不返回）
- 优先级：P0

### UT-03 趋势指标聚合正确

### UT-07 高风险数不随阈值调整变化
