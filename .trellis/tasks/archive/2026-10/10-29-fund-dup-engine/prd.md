# 重复度分析引擎（PRD）

## Goal

对项目申报内容做可解释的多维重复度分析，输出项目对级与项目级结果，并支持本地算法与外部大模型的可配置融合。结果是趋势归因、投入态势与辅助决策的唯一事实来源。

## 范围

- 分析配置（权重、阈值、Top-K、同期窗口、大模型开关/权重/连接）。
- 文本归一化、分词、TF-IDF、分维度相似度、标签/节点相似度。
- 本地分 + 可选大模型语义分的加权融合与降级。
- 分析运行（全量/单项目/预检）、项目对落库、项目快照聚合。
- 项目报告、Top-K 相似项目、项目对明细、运行历史查询。
- 不做：趋势图表、投入看板、决策建议与报告导出（下游子任务）。

## 功能需求

### F1 分析配置

- 单条生效配置，版本号自增；字段：字段权重（目标/内容/关键技术/节点/标签）、等级阈值（高/中/低）、Top-K（默认 5）、同期窗口天数（默认 30）、大模型开关、本地/大模型权重（默认 70/30）、大模型候选对数（默认 5）、超时（默认 8000ms）。
- 管理员可读取、修改、查看历史；修改写审计；新配置仅影响之后的运行。
- 校验：权重均 ≥0 且总和 >0；阈值满足 `0 < low < medium < high ≤ 100`；本地+大模型权重 >0。
- 读取接口对所有登录用户开放（只读）；修改仅 `ADMIN`。

### F2 文本处理

- 输入：项目目标、研制内容、关键技术（名称+说明）、节点计划（阶段+交付物）、技术方向与关键技术标签；结构化字段缺失时回退附件解析文本。
- 清洗：全角转半角、去 HTML/控制符、统一空白、英文小写、去除页眉页脚噪声。
- 分词：中文字符 2-gram + 英文/数字词 + 术语词典命中词（权重 ×3）；过滤停用词与纯标点。
- 向量：本次运行语料统一 TF-IDF；`tf = 1 + log(count)`，`idf = log((N+1)/(df+1)) + 1`；L2 归一化。
- 结果可解释：每维度输出 Top 关键词与代表性片段。

### F3 分维度与总分

- 目标/研制内容/关键技术：TF-IDF 余弦相似度 ×100。
- 节点计划：阶段名称 Jaccard ×60% + 计划区间重叠率 ×40%，再 ×100。
- 技术标签：技术方向 + 关键技术名称集合 Jaccard ×100。
- 本地总分 = Σ(维度分 × 归一化字段权重)。
- 等级：`≥high` 高、`≥medium` 中、`≥low` 低、否则无明显重复。
- 归因：同组 → `SELF_GROUP`；跨组按首次提交时间与同期窗口判 `PEER_EARLIER/OUR_EARLIER/SIMULTANEOUS`；存储中性 `earlierProjectId`。
- 重复点/差异点：输出每维度 Top 匹配词与原文片段；差异点取低频但高权重词。

### F4 大模型增强（可选）

- 仅对本地分排名前 N 的候选对调用；未配置/未开启时不调用。
- OpenAI 兼容 `POST {baseUrl}/chat/completions`，`temperature=0`，要求纯 JSON。
- 返回 `{semanticScore, overlaps[], differences[], suggestion, reason}`；校验范围与类型，非法响应丢弃。
- 融合：成功对按 `(localW×localScore + llmW×llmScore)/(localW+llmW)`；失败对保留本地分。
- 降级：超时、连接失败、HTTP 非 2xx、JSON 非法、连续 3 次失败 → 停止调用并标记 `llmUsed=false`；不阻断运行。
- 记录每次调用：模型、耗时、token、状态、错误；密钥与正文不写日志。
- 缓存：相同项目对 + 相同文本 hash + 相同配置版本，24h 内复用；缓存命中不重复计费。

### F5 分析运行

- 触发方式：`FULL`（全部非草稿项目）、`PROJECT`（单项目 vs 全量）、`PRECHECK`（草稿或临时文本）。
- 运行记录：触发类型、配置版本、状态、项目数、项目对数、是否用大模型、耗时、错误信息。
- 可选 `analysisDate`（仅 ADMIN/演示回填）：按指定日期生成快照，语料仅包含该日期前已提交的项目，用于构造历史趋势；默认当前时间。
- 并发保护：同一时刻仅允许 1 个 `FULL`/`PROJECT` 运行；重复触发返回 409 或复用进行中的结果（配置为复用）。
- 失败处理：运行标记 FAILED 并保留错误；不写入半成品项目对（事务或按 run 清理）。
- 全量运行后更新 `project.duplicate_score` 与 `risk_level` 为最新快照值。

### F6 快照与查询

- 每个项目每次运行生成 1 条快照：最高分、Top-K 平均分、高风险对数、四类归因计数、风险敞口（仅预算存在时）。
- 项目报告：项目信息、快照、Top-K 相似项目、分维度得分、重复/差异点、归因分布。
- 项目对明细：双方信息、分维度得分、片段、LLM 补充理由（如有）。
- 运行历史：分页，可按类型/状态/时间筛选；允许管理员删除失败运行记录（审计）。
- 查询权限：`GROUP_USER` 仅本组项目；`PMO/ADMIN` 全部；`EXPERT` 已提交项目。

### F7 性能与可解释性

- 单项目分析 ≤2s（本地，300 项目语料）；全量 300 项目 ≤5s；1000 项目 ≤15s。
- 相似对只保留 `totalScore ≥ low` 且每项目 Top-K，避免 O(n²) 全量落库。
- 每个分数可回溯到维度分、权重与关键词；报告中展示计算口径说明。

## 验收标准

- [ ] 固定夹具：完全相同的目标/内容/技术 → 总分 ≥95，等级高。
- [ ] 固定夹具：主题无关的两个项目 → 总分 <30，等级无明显重复。
- [ ] 部分重叠夹具（同一技术方向、不同应用场景）→ 40–80 区间，等级符合阈值。
- [ ] 修改字段权重后重跑，分维度加权结果按新权重复算一致。
- [ ] 同组相似对归因为 `SELF_GROUP`；跨组且时间差 >30 天正确区分在先方；≤30 天归为 `SIMULTANEOUS`。
- [ ] 关闭大模型：运行成功，`llmUsed=false`，项目对有本地分。
- [ ] 模拟大模型超时/500/非法 JSON：运行成功，失败对保留本地分，`llmUsed=false`，`llm_call_log` 有记录。
- [ ] 大模型返回合法 JSON：总分按配置权重融合；权重改为 100/0 时等于本地分。
- [ ] 快照计数与 `analysis_pair` 明细聚合一致（四类归因、高风险数）。
- [ ] 全量运行 300 项目耗时 ≤5s（本地算法）；日志无 API Key。
- [ ] 项目报告接口返回 Top-K、维度分、重复/差异片段；越权访问返回 403。
- [ ] `mvn test` 覆盖分词、相似度、权重、归因、降级、快照一致性。

## 依赖与约束

- 前置：declaration（项目与申报书数据、`submit_time`、技术方向）。
- 大模型密钥仅环境变量；默认关闭，评审可现场开启。
- 不引入向量数据库/模型文件；全部计算在 JVM 内存完成。
