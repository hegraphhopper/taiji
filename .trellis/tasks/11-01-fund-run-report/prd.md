# 分析运行报告查看 — PRD（最小版）

## Goal

在「分析运行」历史记录旁增加「查看报告」，直接展示该次运行已保存的重复项目对，以及具体重复/差异内容，帮助 PMO 快速定位问题。

## 范围

### 本期（已接真实数据）

- 成功运行行增加「查看报告」按钮；失败/进行中不显示。
- 弹窗展示项目对列表：项目 A、项目 B、总分、等级、归因。
- 点击列表行展示明细：双方信息、五维得分、重复点、差异点、模型复核内容。
- 支持「只看高风险」客户端筛选与分页。
- 新增只读接口 `GET /analysis/runs/{id}/pairs`，直接返回该 run 的 `analysis_pair` 已落库结果与项目摘要。
- 前端使用真实接口数据，示例数据与「示例数据」标签已移除。

### 不做

- 新页面、路由、导出、跨运行对比、重新分析、数据库变更。
