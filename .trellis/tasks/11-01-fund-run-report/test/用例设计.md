# 分析运行报告查看 — 用例设计

## 1. 摘要

- 阶段：前端演示（示例数据），后端接口未接入。
- 被测范围：`AnalysisRunsView` 入口、`RunReportDialog` 列表/筛选/分页/明细。
- 验证方式：`npm run typecheck`、`npm run build`、浏览器人工走查。

## 2. 用例

### UT-01 成功运行显示查看报告，失败运行不显示
- 关联需求/AC：AC-01
- 被测对象：`AnalysisRunsView.vue` 操作列
- 前置条件：运行列表含 SUCCESS、FAILED、PRECHECK 各一条。
- 步骤：1. 打开分析运行页；2. 观察操作列。
- 预期结果：SUCCESS 且非 PRECHECK 行显示「查看报告」；FAILED/PRECHECK 行不显示。
- 优先级：P0

### UT-02 报告弹窗展示项目对列表
- 关联需求/AC：AC-02
- 被测对象：`RunReportDialog.vue`
- 前置条件：点击成功运行的「查看报告」。
- 步骤：1. 打开弹窗；2. 检查表头与行数据。
- 预期结果：显示 A/B 项目名称、总分、等级、归因；默认按总分倒序；顶部有「示例数据」提示。
- 优先级：P0

### UT-03 点击行展示重复点与差异点
- 关联需求/AC：AC-03
- 被测对象：`RunReportDialog.vue` 明细区
- 前置条件：列表存在至少一条项目对。
- 步骤：1. 点击第一行；2. 查看明细区。
- 预期结果：显示五维得分、总分/本地分/模型分、重复点（维度、命中词、片段）、差异点；有模型数据时显示大模型分析重复点/差异点/理由。
- 优先级：P0

### UT-04 只看高风险筛选
- 关联需求/AC：AC-04
- 被测对象：`RunReportDialog.vue` 筛选
- 前置条件：示例数据含 HIGH 与非 HIGH。
- 步骤：1. 勾选「只看高风险」；2. 取消勾选。
- 预期结果：勾选后仅显示 HIGH；总数与分页联动；取消后恢复全部。
- 优先级：P1

### UT-05 分页
- 关联需求/AC：AC-04
- 被测对象：`RunReportDialog.vue` 分页
- 前置条件：示例数据超过 10 条。
- 步骤：1. 切换第 2 页；2. 返回第 1 页。
- 预期结果：每页 10 条，页码与总数正确，切换后列表更新。
- 优先级：P1

### UT-06 空态与关闭重置
- 关联需求/AC：AC-05
- 被测对象：`RunReportDialog.vue`
- 前置条件：筛选后无结果；或首次打开。
- 步骤：1. 打开弹窗；2. 关闭后再次打开。
- 预期结果：无结果显示空态；再次打开时筛选、分页、选中项重置。
- 优先级：P2

### UT-07 构建与类型检查
- 关联需求/AC：AC-06
- 被测对象：前端工程
- 步骤：1. `npm run typecheck`；2. `npm run build`。
- 预期结果：均退出码 0。
- 优先级：P0

### UT-08 运行报告返回已落库项目对与可解释片段
- 关联需求/AC：AC-07
- 被测对象：`GET /api/v1/analysis/runs/{id}/pairs`
- 前置条件：3 个近似项目，PMO 触发 FULL 分析。
- 步骤：1. 调用接口；2. 检查数组与首条字段。
- 预期结果：3 条项目对；含双方名称、总分 100、等级 HIGH、中性归因、五维分、重复点非空。
- 优先级：P0

### UT-09 运行报告权限
- 关联需求/AC：AC-07
- 被测对象：同上
- 前置条件：GROUP_USER、EXPERT、ADMIN 账号。
- 步骤：分别调用接口。
- 预期结果：GROUP_USER/EXPERT 403；ADMIN 200；匿名 401。
- 优先级：P0

### UT-10 运行不存在返回 404
- 关联需求/AC：AC-07
- 被测对象：同上
- 步骤：调用不存在的 runId。
- 预期结果：HTTP 404。
- 优先级：P1

### UT-11 无项目对的运行返回空数组
- 关联需求/AC：AC-07
- 被测对象：同上
- 前置条件：插入一条无明细的 SUCCESS 运行。
- 步骤：调用接口。
- 预期结果：`data` 为空数组。
- 优先级：P1

### UT-12 前端使用真实数据
- 关联需求/AC：AC-08
- 被测对象：`AnalysisRunsView` + `RunReportDialog`
- 前置条件：后端运行中，存在运行 #24。
- 步骤：打开报告弹窗并点击首行。
- 预期结果：显示 19 对真实项目、真实项目名与片段；无「示例数据」标签；控制台无错误。
- 优先级：P0
