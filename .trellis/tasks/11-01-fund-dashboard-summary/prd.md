# 工作台真实指标 — PRD

## Goal

工作台顶部 3 个 KPI 当前是写死的占位符；改为按当前用户数据范围聚合的真实数据，作为交付演示的首页。

## 范围

- 新增只读接口 `GET /api/v1/dashboard/summary`（登录用户）。
- 指标口径：
  - 项目总数：当前角色可见的全部项目（PMO/ADMIN 全量，项目组用户本组，专家按现有 `canView` 规则）。
  - 平均最高重复度：可见且已分析项目的最新快照 `max_score` 平均值；无已分析项目时为空。
  - 高风险项目：可见且已分析项目中 `max_score >= 高阈值` 的数量。
  - 同时返回已分析项目数与当前阈值，供前端提示。
- 前端工作台三个 KPI 接入接口，增加加载/空态/错误态，移除 A2/A3 阶段胶囊。
- 技术方向 KPI 保持字典数据不变。

## 不做

- 不修改分析、快照、权限规则。
- 不重做工作台布局、路线图与「下一步」卡片。

## 验收标准

- [x] AC-01 PMO/ADMIN 工作台显示项目总数 60（当前演示库），平均最高重复度与高风险数来自最新快照。
- [x] AC-02 项目组用户只统计本组可见项目；专家按现有可查看规则统计。
- [x] AC-03 无已分析项目时平均分显示「—」，高风险为 0，页面不报错。
- [x] AC-04 接口不可用时 KPI 显示「—」并给出错误提示，不出现控制台错误。
- [x] AC-05 `mvn test`、`npm run typecheck`、`npm run build` 通过。

## 决策记录

- [x] 选择方案 B（专用汇总接口），而非前端复用投入接口：投入接口对 EXPERT 403 且仅统计已立项/在研/结项，口径不一致（依据：用户确认）。
- [x] 项目总数按全部可见项目统计，不按投入口径 41（依据：用户确认）。
