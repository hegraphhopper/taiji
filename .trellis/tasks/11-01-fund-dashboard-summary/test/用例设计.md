# 工作台真实指标 — 用例设计

## 1. 摘要

- 被测范围：`GET /api/v1/dashboard/summary` 与工作台三个 KPI。
- 重点：数据范围、最新快照口径、无数据/错误态、构建。

## 2. 用例

### UT-01 PMO 汇总全部可见项目
- AC：AC-01
- 被测对象：`DashboardQueryService#summary`
- 前置：3 个项目（2 同组、1 跨组），PMO 触发 FULL 分析。
- 步骤：调用接口。
- 预期：`projectCount=3`、`analyzedCount=3`、`avgMaxScore` 为三条快照最高分平均值、`highRiskCount` 与阈值比较一致。
- 优先级：P0

### UT-02 项目组用户仅统计本组
- AC：AC-02
- 前置：本组 2 个项目、他组 1 个项目；均有快照。
- 步骤：项目组用户调用接口。
- 预期：`projectCount=2`，平均分/高风险只基于本组。
- 优先级：P0

### UT-03 专家按可见规则统计
- AC：AC-02
- 前置：REVIEWING 项目（他组）、本组 SUBMITTED 项目、本组 DRAFT 项目。
- 步骤：专家调用接口。
- 预期：统计 REVIEWING + 本组 SUBMITTED，不含 DRAFT。
- 优先级：P1

### UT-04 无已分析项目
- AC：AC-03
- 前置：有项目但无快照。
- 步骤：调用接口。
- 预期：`analyzedCount=0`、`avgMaxScore=null`、`highRiskCount=0`，HTTP 200。
- 优先级：P0

### UT-05 空库
- AC：AC-03
- 前置：无项目。
- 步骤：调用接口。
- 预期：`projectCount=0`、`avgMaxScore=null`、`highRiskCount=0`。
- 优先级：P1

### UT-06 前端 KPI 渲染
- AC：AC-01/AC-04
- 被测对象：`DashboardView.vue`
- 步骤：登录后打开工作台；模拟接口失败。
- 预期：成功时显示真实值；失败时显示「—」和错误提示，控制台无报错。
- 优先级：P0

### UT-07 构建
- AC：AC-05
- 步骤：`mvn -q test`、`npm run typecheck`、`npm run build`。
- 预期：全部退出码 0。
- 优先级：P0
