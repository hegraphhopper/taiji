## 1. 背景与问题

电科太极通过平台基金、创新基金等自投资金支持各业务部门技术创新，申报项目逐年累积。立项书、研制任务书、结项报告分散在不同系统，评审依赖专家逐份翻阅，存在三类问题：

1. **看不见**：项目目标、研制内容、关键技术、节点计划没有统一结构化沉淀，跨部门检索困难。
2. **算不清**：技术点撞车、研制内容重复只能到立项会上发现，重复投入无法量化，预算浪费不可见。
3. **管不住**：缺少重复度随时间变化的趋势与归因，无法判断问题出在本组重复申报还是跨组撞车，治理动作缺乏依据。

本产品把“重复账”算清楚：结构化申报书 → 多维重复度分析 → 趋势与归因 → 投入态势 → 新项目辅助决策，形成自投项目治理闭环。

## 2. 目标与成功指标

### 2.1 产品目标

- 让项目管理人员在**立项前**看到新项目与存量项目的重复程度、重复点与差异点。
- 让管理人员看到**重复度随时间的变化趋势**，并按“本组内部 / 他组在先 / 我方在先 / 同期并行”归因。
- 让技术创新投入**可量化呈现**，包括重复投入风险敞口。
- 让申报、评审、立项、结项过程**可追溯**，形成可复用的数据资产。

### 2.2 成功指标（评审可演示）

| 指标 | 目标 |
|------|------|
| 重复度分析覆盖 | 对全部已提交/在研/结项项目可一键分析，输出项目级与项目对级结果 |
| 分析时延 | 300 个项目、4.5 万字符/项目规模下，单次全量分析 ≤ 5s（不含外部大模型调用） |
| 归因可解释 | 每个高风险项目可下钻到具体相似项目、重复技术点与差异点 |
| 趋势可用 | 至少 6 个月度数据点的重复度趋势与归因构成，支持按项目组/技术方向/基金类型筛选 |
| 决策闭环 | 新项目预检输出风险等级、建议动作、预计重复投入金额，并可导出决策报告 |
| 数据可信 | 关键指标均可从项目与快照明细复算，审计日志覆盖写操作 |

## 3. 用户与权限

| 角色 | 代码 | 主要职责 | 数据范围 |
|------|------|----------|----------|
| 系统管理员 | `ADMIN` | 用户/角色/项目组/技术方向/分析权重配置/审计日志 | 全部 |
| 基金办（项目管理人员） | `PMO` | 全所项目查看、形式审查、重复度分析、趋势归因、投入态势、辅助决策、报告导出 | 全部 |
| 项目组用户 | `GROUP_USER` | 维护本组项目与申报书、上传附件、发起预检、查看本组分析结果 | 本组项目 |
| 评审专家 | `EXPERT` | 查看被指派/全量申报项目的重复度报告、填写评审意见与评分 | 被评审项目（只读项目内容） |

权限规则：

- 认证采用本地账号 + JWT；密码 BCrypt 存储；登录失败锁定策略可配置（默认 5 次/10 分钟）。
- 接口按角色鉴权；数据范围在服务层强制过滤，不能仅靠前端隐藏。
- 项目组用户只能编辑本组 `DRAFT`/`REJECTED` 状态项目；`SUBMITTED` 之后只读，需撤回后修改。
- 评审专家不可修改项目内容，只能提交评审记录。
- 所有写操作（含分析运行、配置变更、导出）写入审计日志。

## 4. 业务流程

### 4.1 申报与治理主流程

```text
项目组创建草稿
  → 填写目标/研制内容/关键技术/节点计划/预算/成员
  → 上传申报书附件（自动解析回填）
  → 申报前重复度预检（可选，高风险先调整）
  → 提交申报
  → 基金办形式审查（材料完整性 + 重复度分析）
  → 专家评审（评分 + 意见，参考重复度报告）
  → 立项 / 驳回（驳回可修改后重提）
  → 在研执行 / 结项
  → 结项材料回流为存量知识，参与后续查重
```

### 4.2 重复度分析与归因闭环

```text
触发分析（全量 / 单项目 / 申报前预检）
  → 结构化文本归一化与分词
  → 分维度相似度（目标/研制内容/关键技术/节点计划/技术标签）
  → 本地算法得分 + 可选大模型语义得分，按权重融合
  → 生成项目对结果（相似度、重复点、差异点、归属关系、先后方向）
  → 生成项目级快照（最高分、高风险对数、归因计数、风险敞口）
  → 趋势聚合（按月/季度）与归因构成
  → 管理人员下钻：趋势 → 项目 → 相似项目对 → 具体重复文本
  → 预检结果进入决策记录，支撑立项决策
```

### 4.3 归因判定口径

以相似项目对的**在先项目归属**判定，四类互斥：

| 归因 | 判定 | 管理含义 |
|------|------|----------|
| 本组内部重复 `SELF_GROUP` | 两项目同属一个项目组 | 我方重复申报/自我复制，属内部治理问题 |
| 他组在先 `PEER_EARLIER` | 跨组，且对方项目申报时间更早 | 我方撞他组，需说明差异或合并 |
| 我方在先 `OUR_EARLIER` | 跨组，且我方项目申报时间更早 | 他方撞我方，需保护我方投入/协调 |
| 同期并行 `SIMULTANEOUS` | 跨组，申报时间差在配置窗口内（默认 30 天） | 并行立项风险，需协调归口 |

- “我方/他方”以查询视角的项目组为参照；管理人员全所视角下按项目对展示双方归属。
- 申报时间取首次提交时间；无提交时间时退化为创建时间。
- 趋势按分析日期所在月份聚合；同一项目在同一月份多次分析时，趋势取**当月最后一次快照**，避免重复计数。

## 5. 功能需求

### FR-01 组织、用户与权限（foundation 基础 + governance 完整）

- 项目组/部门树维护，支持上下级。
- 用户维护、启用/禁用、重置密码、分配角色与项目组。
- 角色固定四类，支持菜单与接口权限校验。
- 登录、登出、当前用户信息、修改密码。
- 技术方向字典（含关键词），供项目打标与相似度加权。
- 审计日志查询（操作人、动作、资源、时间、IP、结果）。

### FR-02 项目与申报书管理（子任务 declaration，审批流部分移交 governance）

- 项目立项信息：名称、编码、基金类型（平台基金/创新基金/其他）、所属项目组、负责人、技术方向、预算、起止时间、摘要、预期成果。
- 结构化申报内容：
  - 项目目标（多条，排序）
  - 研制内容（多条，排序）
  - 关键技术（名称、说明、难度、排序）
  - 节点计划（阶段、计划起止、交付物、权重）
  - 项目成员（成员、角色、投入人月）
- 附件管理：上传 docx/pdf/txt/md，解析正文并按章节标题抽取“目标/研制内容/关键技术/节点计划”，支持一键回填与人工修正；解析失败可见原因并可重试。
- 项目状态机：`DRAFT → SUBMITTED → REVIEWING → APPROVED / REJECTED`，`APPROVED` 后可进入 `IN_PROGRESS → COMPLETED / TERMINATED`；非法流转拒绝。
- 提交、撤回、形式审查、专家评审（评分 + 意见 + 结论）、立项、驳回、结项。
- 列表检索：名称/编码/负责人、项目组、基金类型、技术方向、状态、预算区间、时间范围、重复度区间；分页排序。
- 详情页按 Tab 展示全部信息、附件、评审记录、审批轨迹、重复度结果。

### FR-03 重复度分析引擎（子任务 dup-engine）

- 分析配置：字段权重、等级阈值、Top-K、同期窗口、本地/大模型权重、大模型开关与连接参数，管理员可改并留痕。
- 文本处理：清洗、中文分词（字符 n-gram + 领域术语词典）、TF-IDF 向量、Jaccard 标签相似度。
- 维度得分：目标、研制内容、关键技术、节点计划、技术标签，加权为本地总分（0–100）。
- 外部大模型增强（可选）：对候选相似对做语义复核，输出语义相似度、重复点、差异点、建议；连接失败/超时/未配置时自动降级为本地算法，不阻断分析。
- 融合公式：`最终分 = (本地权重 × 本地分 + 大模型权重 × 大模型分) / (本地权重 + 大模型权重)`；大模型不可用时权重回退为纯本地。
- 分析运行：全量分析、单项目分析、申报前预检；记录运行状态、耗时、项目数、项目对数、是否使用大模型。
- 结果持久化：项目对结果（分维度得分、总分、等级、归因关系、先后方向、重复点、差异点、匹配片段）与项目级快照。
- 查询接口：项目重复度报告、Top-K 相似项目、项目对明细、运行历史。
- 性能与稳定性：单项目分析 ≤ 2s（不含大模型），全量 300 项目 ≤ 5s；大模型调用并发受控、超时与重试有上限。

### FR-04 重复度趋势与归因看板（子任务 trend-attribution）

- 趋势指标：月度/季度平均最高重复度、平均重复度、高风险项目数、分析项目数、项目对数。
- 归因构成：本组内部、他组在先、我方在先、同期并行四类计数与占比，堆叠趋势。
- 筛选：时间范围、项目组、技术方向、基金类型、等级；项目组用户仅看本组。
- 下钻：趋势点 → 当月项目列表 → 项目对明细 → 重复/差异文本对比。
- 可视化：折线 + 堆叠柱 + 热力图（项目组 × 月份，或技术方向 × 项目组），支持图例开关与导出 CSV。
- 结论辅助：自动生成“本期重复度上升/下降、主要归因、需关注项目组”的文字摘要。

### FR-05 技术创新投入态势（子任务 investment）

- 核心指标：投入总额、项目数、在研/结项数、平均预算、平均重复度、高风险项目数、重复投入风险敞口。
- 风险敞口口径：`Σ(项目预算 × 项目最高重复度 / 100)`，仅统计已立项/在研/结项项目；可按维度分解。
- 多维分析：按年度、基金类型、项目组、技术方向；同比/环比；Top 技术方向；组间投入对比。
- 可视化：KPI 卡、年度堆叠柱、技术方向矩形树图/条形图、项目组对比、重复度-投入散点（气泡大小=预算）。
- 下钻到项目列表；筛选条件与趋势页一致。

### FR-06 新项目辅助决策（子任务 decision）

- 预检入口：新建草稿直接预检，或选择已有草稿/申报项目预检；支持粘贴文本快速预检。
- 预检输出：
  - 综合风险分与等级
  - Top-5 相似项目（项目组、负责人、状态、预算、分维度相似度）
  - 重复技术点 / 重复研制内容 / 差异点
  - 建议动作：可立项 `APPROVE`、补充差异说明 `EXPLAIN`、建议合并 `MERGE`、建议终止/转向 `TERMINATE`
  - 预计重复投入金额（预算 × 重复度）
  - 建议评审专家（按技术方向、历史评审负载）
- 决策规则可配置（阈值 → 建议动作映射），大模型可给出文字理由，规则结果始终保留。
- 决策记录：保存预检快照、建议、操作人、时间，可追溯。
- 报告导出：Word（决策报告，含项目信息、风险结论、相似项目表、重复/差异点、建议）与 Excel（相似项目明细）。

### FR-07 报告与数据导出（子任务 decision / delivery）

- 项目重复度分析报告导出 Word。
- 趋势与归因数据导出 CSV/Excel。
- 投入态势数据导出 Excel。
- 导出文件带生成时间、筛选条件与数据口径说明。

### FR-08 系统管理与审计（foundation 写入 + governance 查询与管理）

- 分析权重与阈值配置、建议规则配置、大模型连接配置（密钥脱敏展示）。
- 审计日志：登录、用户/角色/字典变更、项目状态流转、附件上传删除、分析运行、配置变更、报告导出。
- 审计日志支持按时间、操作人、动作、资源类型筛选，不可在界面删除。

### FR-09 演示数据与交付（子任务 delivery）

- 内置演示数据：3 个年度、8 个项目组、约 60 个项目，覆盖本组重复、他组在先、我方在先、同期并行、低重复等场景。
- 开源样例附件：从公开开源项目文档中选取 4–6 份中文/英文材料，作为申报书附件解析演示；来源与许可见 `docs/demo-data.md`。
- 数据库：MySQL 8 建表/初始化脚本、H2 演示模式、备份与恢复脚本、可恢复备份文件。
- 文档：README、需求分析、系统设计（架构/模块/数据库/接口）、用户手册、演示脚本。
- 截图/演示：关键页面运行截图与 3–5 分钟演示视频脚本。

## 8. 验收标准

### 8.1 端到端验收场景

- [ ] AC-01（治理收尾阶段）管理员登录后可维护项目组、用户、角色、技术方向；项目组用户登录后仅能看到本组项目。
- [ ] AC-02 项目组用户创建项目，完整填写目标/研制内容/关键技术/节点/成员/预算，上传 docx 申报书后系统解析正文并回填至少“目标、研制内容、关键技术”三类内容。
- [ ] AC-03（治理收尾阶段）项目提交后经基金办形式审查、专家评分，最终立项；全过程在审批轨迹与审计日志中可查；非法状态流转被拒绝。
- [ ] AC-04 对全量项目运行分析，生成项目对与项目快照；高风险项目可查看 Top-5 相似项目、分维度得分、重复点与差异点。
