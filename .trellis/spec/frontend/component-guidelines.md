# 前端组件规范

- 优先复用已有组件、布局、设计 token 和交互模式，保持用户要求与项目品牌。
- 新界面在软件设计或实现中按需调用 `frontend-design`，先确认页面用途、用户、内容层级和视觉方向。
- 已有界面改进使用 `redesign-existing-projects`，在现有技术栈内做有依据的局部改进。
- 两项技能是当前步骤内的指导，不自行切换阶段；其字体、颜色、布局和动效建议服从项目规范，不机械套用风格或添加依赖。
- 组件职责保持清晰，数据和回调通过既有 props 模式传递；复用语义 HTML、原生控件和 CSS。
- 表单提供标签、可理解的校验和错误恢复；按钮可用键盘操作，焦点可见，动效尊重 reduced motion。
- 首次项目调研补充真实组件示例、样式入口和 token 定义位置。
